# TravelLearning

TravelLearning is a simple educational travel management project built with .NET and Blazor.

The main goal of this project is to learn how a real-world application is structured and how different layers of an application communicate with each other.

The project will be developed step by step, starting from a very simple contract registration system and gradually adding more features.

## Initial Goals

- Learn Blazor components and component-based UI
- Understand the flow between UI, Service, Repository, and Database
- Register simple travel contracts
- Support Hotel and Flight contracts
- Store data using Entity Framework Core
- Display contract details
- Create printable contract pages
- Generate PDF files
- Practice layered / clean project architecture

## Planned Architecture

The solution will contain the following projects:

- `TravelLearning.Core`
- `TravelLearning.Application`
- `TravelLearning.Infrastructure`
- `TravelLearning.Panel`

Each part of the project will be implemented gradually as part of the learning process.

## Project Status

🚧 Currently under development and used primarily for learning and practice.
